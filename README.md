
# LearnWise AI

AI-Powered Course Learning Assistant

## Features
- Upload course PDF
- Ask AI questions about course content
- Search timestamps
- Generate MCQs
- Generate flashcards
- Generate revision notes
- Track student progress

## Technologies
- Python
- Streamlit
- Ollama (Llama 3.2)
- SQLite

## Run Locally
1. Install Python and Ollama.
2. Download the model: `ollama pull llama3.2`
3. Install dependencies: `pip install -r requirements.txt`
4. Run the application: `streamlit run app_sqlite.py`

Note: Ollama must be running locally for AI features.
